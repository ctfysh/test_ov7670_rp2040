# Raw Bayer VGA Half-Frame Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Verify OV7670 Raw Bayer output on YD-RP2040: capture VGA 640×480 8-bit BGGR via two 640×240 half-frame windows (CAM2 protocol), validate the Bayer math, and produce a demosaiced BMP.

**Architecture:** Firmware switches the OV7670 window register (VSTRT/VSTOP) between upper (rows 15–252) and lower (rows 252–492) halves of the VGA array; each 640×240 half-frame (153,600 B) fits the existing single DMA buffer unchanged. Host tool `bayer_capture.py` syncs the new `"CAM2"` 8-bit frame protocol, grabs N upper + N lower half-frames, stitches pairs into 640×480 `.raw`. `bayer_demosaic.py` does BGGR bilinear demosaic (G-first, R/B via G-corrected interpolation) and writes 24bpp BMP.

**Tech Stack:** PlatformIO (arduino-pico, `maxgerhardt/platform-raspberrypi.git`), C/C++ firmware (existing PIO+DMA pipeline), Python 3 stdlib + `pyserial` (capture CLI), `numpy` (demosaic + tests), `unittest` (test suite, zero-dependency math layer).

## Global Constraints

- **Worktree**: implement ONLY inside `.worktrees/exp-raw-bayer` (branch `exp/raw-bayer`). Never touch `main` or `impl/uvc` worktrees.
- **Memory**: RP2040 264 KB SRAM cannot hold a full VGA Bayer frame (307,200 B > 270,336 B). Keep the single-buffer architecture: `FRAME_BYTES` must stay 153,600 — the DMA buffer, `frames[]`, VSYNC/DMA ISR logic, and single-buffer send flow are UNCHANGED.
- **Firmware frame size**: with `-DFRAME_W=640 -DFRAME_H=240`, `FRAME_BYTES` must be `FRAME_W * FRAME_H` (×1, 8-bit Bayer) for the CAM2 build — NOT `FRAME_W * FRAME_H * 2`. Use `#ifdef RAW_BAYER` to branch in `main.cpp` only; the CAM1 path stays ×2.
- **CAM2 protocol**: `"CAM2"` (4 B) + W (u16 BE) + H (u16 BE) + W×H bytes raw 8-bit Bayer. New magic `'2'` for the RAW_BAYER build; CAM1's `"CAM1"` untouched.
- **'T' command**: 1 raw byte param: `0x00` = upper half, `0x01` = lower half. Ack = `DBG1 + 0xF9 + half`; `0xFF` in the ack slot means SCCB write failed. Window switch takes effect after ~2 frames — host MUST wait ~0.5 s after 'T' before capturing.
- **Window register math (datasheet §6.5, p.48–53)**: `VSTRT=(0x19<<2)|VREF[1:0]`; `VSTOP=(0x1A<<2)|VREF[3:2]`; `HSTART=(0x17<<3)|HREF[2:0]`; `HSTOP=(0x18<<3)|HREF[5:3]`. Exact window values: full VGA=(15,492)→`0x19=0x03, 0x1A=0x7B, VREF=0x03`; upper=(15,252)→`0x19=0x03, 0x1A=0x3F, VREF=0x03`; lower=(252,492)→`0x19=0x3F, 0x1A=0x7B, VREF=0x00`. **TSLB[0]=0 (reg 0x3A) must be written before any window change.**
- **VREF read-modify-write**: preserve bits[7:4] (AGC gain [9:8]) — read 0x03, mask `&0xF0`, OR in the new low nibble, write back.
- **Raw Bayer register set (Table 2-2 + COM7=0x01, corrected 2026-08-14)**: CLKRC=0x80 (fINT=XCLK/2 on the 20.8 MHz PWM build), DBLV=0x0A, COM7=0x01, COM15=0xD0, MVFP=0x07, COM3=0x00, COM14=0x18 (bit4+bit3 open the 0x73 gate; bits[2:0]=000 PCLK /1), TSLB=0x00, HSTART=0x11, HSTOP=0x61, HREF=0x80, VSTART=0x03, VSTOP=0x7B, VREF=0x03, SCALING_XSC=0x00 (scaler bypass), SCALING_YSC=0x00, SCALING_DCWCTR=0x00 (no down sampling; default 0x11 = HDS by 2 → 2 PCLK/byte dup), SCALING_PCLK_DIV=0x08 (bit[3]=1 bypass divider, matches RGB565), REG74=0x20 (Horizontal Scaling Ratio 1x, Table 6-1), SCALING_PCLK_DELAY=0x02. **T7 root cause + fix (CONFIRMED 2026-08-14)**: in raw mode the sensor presents each distinct byte for 2 PCLKs over a 1280-PCLK line — dup_even=1.000 persisted across SEVEN live-tested register configs (XSC/YSC=0x00, PCLK_DIV=0xF0, DCWCTR=0x00, COM14=0x18, PCLK_DIV=0x08, REG74=0x20, minimal table) → NOT register-fixable. The fix is in the PIO program: sample every 2ND PCLK rising edge (camera.pio 6-instr loop) → recovers all 640 distinct bytes/line. Verified live: dup_even 1.000→0.385; clean Bayer same-plane signature at 640 (colLag2=0.426 >> colLag1=0.146), absent at 320 → keep FRAME_W=640. Registers kept at best-known config above (test_01 readback asserts them; they match the verified RGB565 scaling block).
- **'R' readback**: keep 17 registers (count `0x11`); the RAW_BAYER build replaces the list with: `0x0A, 0x0B, 0x12, 0x40, 0x15, 0x11, 0x6B, 0x1E, 0x13, 0x17, 0x18, 0x19, 0x1A, 0x03, 0x32, 0x70, 0x71`. COM7 expected `0x01`.
- **Tooling constraint (user-confirmed)**: MCP `upload_firmware` is blocked by policy → always use CLI: `pio run -e rpipico -t upload --upload-port <port>`. Serial read discipline: large `read(4096)` + internal buffer + `find()` sliding window (from `test_hw_integration.py::SerialStream`). Never `read(1)` byte-at-a-time on the frame stream.
- **Test discipline**: tests NEVER send `'B'` (BOOTSEL reboot). Math tests must be hardware-free. Run: `python3 -m unittest discover -s test -p "test_*.py"`.
- **BMP convention** (match `capture.py::rgb565_to_bmp`): 24bpp BGR, bottom-up rows, `row_size=(w*3+3)&~3`, 54-byte header, no compression.
- **Existing tools untouched**: `capture.py`, `live_view.py`, `verify_frame.py` remain CAM1/RGB565 tools — do not modify their protocol handling. New Bayer tools are new files.
- **Frame rate reality**: VGA full ~13 fps sensor-side, but USB CDC send of 153,600 B ≈ 0.23 s/frame → ~4.3 fps host-side ceiling. Timing assertions must tolerate this.

def _make_cfa(h, w, pattern, r, g, b):
    """按 pattern 填充 CFA: R 位置=r, G 位置=g, B 位置=b (uint8)。"""
    cfa = np.zeros((h, w), dtype=np.uint8)
    for y in range(h):
        for x in range(w):
            ch = bd.cfa_color(pattern, y, x)
            cfa[y, x] = {"R": r, "G": g, "B": b}[ch]
    return cfa

**Implementation notes (exactness argument)**:
- `demosaic_bayer` is vectorized (np.roll shifts + valid-mask) — 8-neighbor same-color gather on RGGB reduces to the classic geometry: G at R/B uses the 4 orthogonal G; R at G uses the 2 collinear R; R at B uses the 4 diagonal R. Constant input → every gather = the constant (correction ratio exactly 1.0). Linear G ramp → bilinear interpolants reproduce the linear function exactly in the interior (integer-exact float64), and symmetric G at R/B neighbor positions makes G-correction an exact 1:1 ratio.
- `nearest_neighbor_demosaic`: block replication `(R,G,B) = (cfa[by,bx], cfa[by,bx+1], cfa[by+1,bx+1])`, `by=y&~1, bx=x&~1`; raises ValueError for odd dimensions (Bayer block requires even h/w).

- Module import-safe: argparse lives only inside `main()`, guarded by `if __name__ == "__main__"` — no module-level `sys.argv` (so `test_bayer_math.py` imports it without a shim).

模块级无 sys.argv 解析 (CLI 全在 main(), __main__ 守卫) -> 可被 unittest import。

用法:
  python3 bayer_demosaic.py in.raw --width 640 --height 480 --pattern RGGB -o out.bmp
  python3 bayer_demosaic.py in.raw --width 640 --height 240 --nearest -o out.bmp
"""

import argparse
import struct

import numpy as np

DEFAULT_PATTERN = "RGGB"  # spec §6.1: 偶行偶列=R, 偶行奇列=G, 奇行偶列=G, 奇行奇列=B


def cfa_color(pattern, y, x):
    """(y,x) 处色彩: pattern 按行主序覆盖 2x2 块。"""
    return pattern[(y & 1) * 2 + (x & 1)]


def _color_map(pattern, h, w):
    """(h, w) 字符数组: 每个像素的颜色 ('R'/'G'/'B')。"""
    yy = np.arange(h)[:, None] & 1
    xx = np.arange(w)[None, :] & 1
    return np.array(list(pattern))[yy * 2 + xx]


def _valid_mask(h, w, dy, dx):
    """True where (y+dy, x+dx) 在界内 (避免 np.roll 的环绕贡献)。"""
    y = np.arange(h)[:, None]
    x = np.arange(w)[None, :]
    return (y + dy >= 0) & (y + dy < h) & (x + dx >= 0) & (x + dx < w)


def _gather_avg(src, h, w, target_mask, kernel):
    """每个像素: 在 kernel 偏移的邻居里, 对 target_mask 为真的位置,
    用 src 的值做有效掩码平均 (无有效邻居时返回 0)。"""
    vals = np.zeros((h, w), dtype=np.float64)
    cnt = np.zeros((h, w), dtype=np.float64)
    for (dy, dx) in kernel:
        shifted_src = np.roll(src, (-dy, -dx), axis=(0, 1))
        shifted_tgt = np.roll(target_mask, (-dy, -dx), axis=(0, 1))
        take = shifted_tgt & _valid_mask(h, w, dy, dx)
        vals += np.where(take, shifted_src, 0.0)
        cnt += take
    return vals / np.maximum(cnt, 1.0)


def demosaic_bayer(cfa, pattern=DEFAULT_PATTERN):
    """双线性去马赛克 (G-first + G 校正 R/B), 返回 (h,w,3) uint8 RGB。

    cfa: 2D uint8 (h, w)。边界像素只用界内同色邻居 (valid-mask)。
    对线性/常量 CFA 数学精确 (测试向量可逐像素断言)。
    """
    h, w = cfa.shape
    cfa_f = cfa.astype(np.float64)
    colormap = _color_map(pattern, h, w)
    is_g = colormap == "G"
    is_r = colormap == "R"
    is_b = colormap == "B"

    kernel8 = [(dy, dx) for dy in (-1, 0, 1) for dx in (-1, 0, 1)
               if not (dy == 0 and dx == 0)]

    # G: R/B 位置 = 同色 (正交) G 邻域平均
    g_avg = _gather_avg(cfa_f, h, w, is_g, kernel8)
    g = np.where(is_g, cfa_f, g_avg)

    # R: 缺失位置 = 同色邻域平均 * (G_here / G_at_R_neighbors) 校正
    r_avg = _gather_avg(cfa_f, h, w, is_r, kernel8)
    g_at_r = _gather_avg(g, h, w, is_r, kernel8)
    r = np.where(is_r, cfa_f, r_avg * (g / np.maximum(g_at_r, 1e-9)))

    # B: 对称
    b_avg = _gather_avg(cfa_f, h, w, is_b, kernel8)
    g_at_b = _gather_avg(g, h, w, is_b, kernel8)
    b = np.where(is_b, cfa_f, b_avg * (g / np.maximum(g_at_b, 1e-9)))

    rgb = np.stack([r, g, b], axis=-1)
    return np.clip(rgb, 0, 255).astype(np.uint8)


def nearest_neighbor_demosaic(cfa, pattern=DEFAULT_PATTERN):
    """确定性 2x2 块复制去马赛克, 返回 (h,w,3) uint8 RGB。

    out[y,x] = (cfa[by,bx], cfa[by,bx+1], cfa[by+1,bx+1]), by=y&~1, bx=x&~1
    (块内行主序 tie-break)。要求 h,w 均为偶数 (Bayer 2x2 块)。pattern 仅用于
    校验块布局; 实际取值按 RGGB 块几何。
    """
    h, w = cfa.shape
    if h % 2 != 0 or w % 2 != 0:
        raise ValueError("nearest_neighbor_demosaic requires even h and w")
    by = np.arange(h) & ~1
    bx = np.arange(w) & ~1
    rgb = np.zeros((h, w, 3), dtype=np.uint8)
    rgb[:, :, 0] = cfa[by, :][:, bx]
    rgb[:, :, 1] = cfa[by, :][:, bx + 1]
    rgb[:, :, 2] = cfa[by + 1, :][:, bx + 1]
    return rgb


def rgb_to_bmp(w, h, rgb):
    """24bpp BGR bottom-up BMP (仿 capture.py::rgb565_to_bmp 约定)。

    rgb: (h, w, 3) uint8, RGB 顺序; 输出字节序 BGR, 行自底向上, 行填充
    row_size=(w*3+3)&~3, 54B 头, BI_RGB 无压缩。
    """
    row_size = (w * 3 + 3) & ~3
    data_size = row_size * h
    header = struct.pack("<2sIHHI", b"BM", 54 + data_size, 0, 0, 54)
    header += struct.pack("<IiiHHIIiiII", w, h, 1, 24, 0, data_size, 0, 0, 0, 0)
    body = bytearray()
    for y in range(h - 1, -1, -1):
        bgr = np.flip(rgb[y], axis=1).astype(np.uint8)
        body += bgr.tobytes()
        body += b"\x00" * (row_size - w * 3)
    return header + bytes(body)


def main(argv=None):
    p = argparse.ArgumentParser(
        description="Bayer CFA -> RGB 去马赛克 / BMP 输出 (8-bit raw 输入)")
    p.add_argument("input", help="raw 8-bit Bayer 文件 (w*h 字节)")
    p.add_argument("--width", type=int, required=True, help="帧宽")
    p.add_argument("--height", type=int, required=True, help="帧高")
    p.add_argument("--pattern", default=DEFAULT_PATTERN,
                   choices=["RGGB", "BGGR", "GRBG", "GBRG"],
                   help="CFA 模式 (默认 %(default)s)")
    p.add_argument("--nearest", action="store_true",
                   help="用最近邻 (块复制) 而非双线性")
    p.add_argument("-o", "--output", required=True, help="输出 .bmp")
    args = p.parse_args(argv)

    with open(args.input, "rb") as f:
        data = f.read()
    need = args.width * args.height
    if len(data) < need:
        p.error(f"{args.input}: {len(data)} B < 需要 {need} B "
                f"({args.width}x{args.height})")
    cfa = np.frombuffer(data[:need], dtype=np.uint8).reshape(args.height, args.width)
    if args.nearest:
        rgb = nearest_neighbor_demosaic(cfa, args.pattern)
    else:
        rgb = demosaic_bayer(cfa, args.pattern)
    bmp = rgb_to_bmp(args.width, args.height, rgb)
    with open(args.output, "wb") as f:
        f.write(bmp)
    print(f"{args.output}: {args.width}x{args.height} {args.pattern} "
          f"{'nearest' if args.nearest else 'bilinear'} OK ({len(bmp)} B)")


if __name__ == "__main__":
    main()

## Task 2 — Implement `bayer_capture.py` pure functions + `test/test_bayer_capture.py` (Layers I/J/K)

**Why**: The capture CLI (Task 5) and hardware tests (Task 6) both depend on frame-sync parsing, half-frame stitching, window-command encoding, and per-channel CFA statistics. Pinning these as pure, import-safe, hardware-free functions FIRST lets the CLI be a thin serial wrapper and keeps hardware tests focused on hardware.

**Scope**: create `bayer_capture.py` (pure-function layer ONLY — no CLI yet) and `test/test_bayer_capture.py`. Do not touch firmware or existing tools.

**Design decisions**:
- Import-safe: no module-level `sys.argv` (CLI comes in Task 5, inside `main()` behind `__main__` guard).
- `bayer_capture` imports only `DEFAULT_PATTERN` from `bayer_demosaic` (public API; re-implements the 2-line color-map inline, no private imports).
- Dependencies: `numpy` (already a test dep) + `struct`. No pyserial in the pure layer.
- CAM2 frame: `"CAM2"` (4 B) + W (u16 BE) + H (u16 BE) + W×H payload. `cam2_parse` is the sliding-window sync primitive: scans for magic, validates dims against expected, returns `(frame_start, w, h)` only when the WHOLE frame is present — caller slices and drops.
- Stitch is plain vstack: rows 0..239 = upper, 240..479 = lower. The sensor-side 3-row overlap (rows 252..254 present in both windows) is an accepted artifact of the window-register scheme; per-half stats are the verification lever, stitch does NOT dedupe.
- `cfa_means` returns per-channel means over the sampled CFA (used by Task 6 to prove CFA separation).

```python
#!/usr/bin/env python3
"""Bayer 采集纯函数层 (bayer_capture.py)

无硬件、无串口的纯函数 (import 安全, 无模块级 sys.argv):
  cam2_frame / cam2_parse   : "CAM2" 帧封装与滑动窗口同步解析
  stitch_halves             : 上/下半帧 (640x240) -> 640x480 vstack
  encode_bayer_window       : 'T' 命令参数 (upper -> 0x00, lower -> 0x01)
  cfa_means                 : 逐通道 CFA 均值 (分离度统计)

CLI (pyserial 采集) 在 main() 内, __main__ 守卫 -> 可被 unittest import。
"""

import struct

import numpy as np

from bayer_demosaic import DEFAULT_PATTERN

CAM2_MAGIC = b"CAM2"
CAM2_HEADER = 8  # magic(4) + W(u16 BE) + H(u16 BE)


def cam2_frame(w, h, payload):
    """封装一帧 CAM2: b"CAM2" + W(u16 BE) + H(u16 BE) + payload (len == w*h)。"""
    payload = bytes(payload)
    if len(payload) != w * h:
        raise ValueError(f"payload {len(payload)} B != {w}x{h}={w*h} B")
    return CAM2_MAGIC + struct.pack(">HH", w, h) + payload


def cam2_parse(buf, expected_w, expected_h):
    """在 buf 中查找第一帧完整 CAM2 帧 (滑动窗口同步语义)。

    返回 (frame_start, w, h) | None。完整帧判定: magic + W/H == expected,
    且 frame_start + CAM2_HEADER + w*h <= len(buf)。调用方取走该帧后丢弃
    前缀, 保留尾部残余继续累积。
    """
    idx = 0
    while True:
        idx = buf.find(CAM2_MAGIC, idx)
        if idx < 0:
            return None
        if idx + CAM2_HEADER <= len(buf):
            w, h = struct.unpack_from(">HH", buf, idx + 4)
            if w == expected_w and h == expected_h and \
               idx + CAM2_HEADER + w * h <= len(buf):
                return (idx, w, h)
        idx += 1


def stitch_halves(upper, lower):
    """上/下半帧 -> 全帧: np.vstack (行 0..239=upper, 240..479=lower)。

    传感器窗口: 上窗行 15..254, 下窗行 252..491 -> 3 行重叠 (252..254),
    为窗口寄存器方案的已知伪影; 逐半统计才是验证杠杆, 缝合不去重。
    """
    if upper.shape != lower.shape:
        raise ValueError(f"half shape mismatch: {upper.shape} vs {lower.shape}")
    return np.vstack([upper, lower])


def encode_bayer_window(half):
    """'T' 命令参数字节: upper -> 0x00, lower -> 0x01 (固件契约)。"""
    if half == "upper":
        return b"\x00"
    if half == "lower":
        return b"\x01"
    raise ValueError(f"half must be 'upper' or 'lower', got {half!r}")


def cfa_means(cfa, pattern=DEFAULT_PATTERN):
    """逐通道 CFA 均值: {'R': float, 'G': float, 'B': float} (uint8 采样)。"""
    h, w = cfa.shape
    idx = (np.arange(h)[:, None] & 1) * 2 + (np.arange(w)[None, :] & 1)
    cmap = np.array(list(pattern))[idx]
    out = {}
    for ch in "RGB":
        vals = cfa[cmap == ch]
        out[ch] = float(vals.mean()) if vals.size else 0.0
    return out
```

## Task 3 — Firmware: `ov7670_init_raw_bayer()` + `ov7670_set_bayer_window()` (build-only)

**Why**: The sensor must be switched from the RGB565/QVGA bring-up (used by `capture.py`/`live_view.py`, which must stay working) to 8-bit raw Bayer VGA, and the capture window must jump between the two 640×240 half-frames. This task adds the driver layer ONLY; `main.cpp` wiring happens in Task 4, so the existing RGB565 flow is untouched and this commit is build-verified without a device.

**Scope**: `src/ov7670.h` + `src/ov7670.c` only. No `main.cpp`, no `platformio.ini`, no Python. Build-only verification (`pio run -e rpipico`).

**Design decisions**:
- **`ov7670_init_raw_bayer()`** — full bring-up into raw Bayer VGA 640×480 8-bit: soft reset (COM7=0x80), then the pinned Table 2-2 raw register set + COM7=0x01 (Global Constraint). Same discipline as `ov7670_init()`: 200 µs settle per write, 300 ms final settle.
- **`ov7670_set_bayer_window(half)`** — vertical window switch via the datasheet math: `VSTRT=(VSTART<<2)|VREF[1:0]`, `VSTOP=(VSTOP<<2)|VREF[3:2]`. Pinned register values:
  - upper (rows 15..252): `VSTART=0x03`, `VSTOP=0x3F`, `VREF[3:0]=0x3`
  - lower (rows 252..492): `VSTART=0x3F`, `VSTOP=0x7B`, `VREF[3:0]=0x0`
  - `VREF` read-modify-write preserving bits[7:4] (AGC high bits).
  - `TSLB[0]=0` written FIRST, before any window-register write (pinned constraint).
  - Horizontal window untouched (stays full VGA); only vertical regs change.
- Register macros already exist in `ov7670.h` (VREF 0x03, COM7 0x12, CLKRC 0x11, DBLV 0x6B, COM3 0x0C, COM14 0x3E, TSLB 0x3A, HSTART 0x17, HSTOP 0x18, HREF 0x32, VSTART 0x19, VSTOP 0x1A, SCALING_XSC 0x70, SCALING_YSC 0x71, SCALING_DCWCTR 0x72, SCALING_PCLK_DIV 0x73, SCALING_PCLK_DELAY 0xA2) — only the COM7 raw-bit and window constants are new.
- The 18-entry raw table + terminator mirrors the existing `OV7670_regs` style (`{0xff,0xff}` terminated, `ov7670_write_list`-style loop — reuse the static writer).

// COM7 bits (raw Bayer)
#define OV7670_COM7_SENSOR_RAW 0x01 // sensor raw 8-bit Bayer data out

// Bayer half-window selectors (ov7670_set_bayer_window)
#define OV7670_BAYER_WINDOW_UPPER 0 // rows 15..252
#define OV7670_BAYER_WINDOW_LOWER 1 // rows 252..492

// Written after soft reset; 200us settle per write like OV7670_regs.
static const uint8_t OV7670_raw_bayer_regs[][2] = {
    {0x11, 0x01}, // CLKRC
    {0x6b, 0x0a}, // DBLV
    {0x12, 0x01}, // COM7: sensor raw 8-bit Bayer out
    {0x40, 0xd0}, // COM15: full 0-255 range
    {0x0c, 0x00}, // COM3
    {0x3e, 0x00}, // COM14

    {0x17, 0x11}, // HSTART

    {0x19, 0x03}, // VSTART
    {0x1a, 0x7b}, // VSTOP
    {0x03, 0x03}, // VREF
    {0x70, 0x3a}, // SCALING_XSC
    {0x71, 0x35}, // SCALING_YSC
    {0x72, 0x11}, // SCALING_DCWCTR
    {0x73, 0xf0}, // SCALING_PCLK_DIV
    {0xa2, 0x02}, // SCALING_PCLK_DELAY
    {0xff, 0xff},
};

int ov7670_init_raw_bayer(void) {
  sccb_pins_init();

  // Reset
  ov7670_write_reg(OV7670_REG_COM7, OV7670_COM7_RESET);
  sleep_ms(10);
  ov7670_write_list(OV7670_raw_bayer_regs);

  sleep_ms(300); // tS:REG settling (~10 frames)
  return 0;
}

// Window math (datasheet): VSTRT=(VSTART<<2)|VREF[1:0]; VSTOP=(VSTOP<<2)|VREF[3:2].
// Pinned values:
//   upper: VSTART=0x03,VSTOP=0x3F,VREF[3:0]=0x3 -> rows 15..252
//   lower: VSTART=0x3F,VSTOP=0x7B,VREF[3:0]=0x0 -> rows 252..492
// TSLB[0]=0 MUST be written before any window-register write.
int ov7670_set_bayer_window(uint8_t half) {
  uint8_t vstart, vstop, vref_lo;
  if (half == OV7670_BAYER_WINDOW_UPPER) {
    vstart = 0x03;
    vstop = 0x3f;
    vref_lo = 0x03;
  } else if (half == OV7670_BAYER_WINDOW_LOWER) {
    vstart = 0x3f;
    vstop = 0x7b;
    vref_lo = 0x00;
  } else {
    return -1;
  }

  if (ov7670_write_reg(OV7670_REG_TSLB, 0x00) != 0) return -1;

  // VREF read-modify-write: preserve bits[7:4] (AGC high bits)
  uint8_t vref = 0;
  if (ov7670_read_reg(OV7670_REG_VREF, &vref) != 0) return -1;
  vref = (uint8_t)((vref & 0xF0) | vref_lo);

  if (ov7670_write_reg(OV7670_REG_VSTART, vstart) != 0) return -1;
  if (ov7670_write_reg(OV7670_REG_VSTOP, vstop) != 0) return -1;
  if (ov7670_write_reg(OV7670_REG_VREF, vref) != 0) return -1;
  sleep_us(200);

  return 0;
}

**Why**: This is the first on-hardware consumer of the Task 2/4 contract: it drives the firmware window switch, syncs the 640×240 half-frame stream, stitches full 640×480 frames, and emits per-channel CFA statistics (the separation proof) plus the raw/demosaiced artifacts. **Design decisions**:
- **Import-safety kept**: `pyserial` imported inside `main()` only; stdlib `os`/`time`/`json` may move to top (no side effects, no `sys.argv`). No module-level argv — unlike `capture.py` (which is why its tests need an argv shim; `bayer_capture` never will).
- **Big-read streaming**: a `_Stream` wrapper does `ser.read(4096)` into an internal buffer (never byte-at-a-time); frame sync uses the pinned `cam2_parse` sliding window; `DBG1\xF9` acks are found the same way. Diagnostic packets (`DBG1`/other markers) pass through harmlessly — the sync loop only matches `CAM2`.
- **Protocol flow per pair** (matches pinned contract):
  1. `b"T" + encode_bayer_window("upper")` → wait `DBG1\xF9\x00` ack
  2. sleep 0.5 s (~2 frames) for window settle
  3. capture one upper frame (640×240, 153,600 B) via `cam2_parse`
  4. `b"T" + encode_bayer_window("lower")` → wait `DBG1\xF9\x01` ack
  5. sleep 0.5 s; capture one lower frame
  6. `stitch_halves` → full 640×480; save upper/lower/full `.raw`; `cfa_means` per half and full
- **First command guarantee**: the CLI always sends `'T' upper` before any capture (after init the window is full VGA — frames before the first 'T' are not a valid half).
- **Outputs** (dir default `bayer_frames/`): `upper_NNN.raw`, `lower_NNN.raw`, `frame_NNN_640x480.raw`, optional `frame_NNN_640x480.bmp` (`--bmp`, via `bayer_demosaic`), and `stats.json` with per-pair + overall per-channel means (used by the Task 6 separation assertion and the Task 7 BMP archive).
- **Geometry pinned**: W=640, H=240 hardcoded in the CLI (matches firmware `FRAME_W/H` under RAW_BAYER). No CLI override — the camera is either in this mode or not; a mismatch shows up as a sync timeout.

# ---- CLI (pyserial; imported inside main() so the pure layer stays dep-free) ----

def _find_port():
    """Auto-detect the YD-RP2040 CDC port (macOS: /dev/cu.usbmodem*)."""
    try:
        import serial.tools.list_ports
        cdc = [p.device for p in serial.tools.list_ports.comports()
               if 'usbmodem' in p.device or 'usbserial' in p.device or 'ttyACM' in p.device]
    except Exception:
        cdc = []
    if len(cdc) == 1:
        return cdc[0]
    if len(cdc) > 1:
        return cdc[0]  # first match; --port overrides
    raise SystemExit("no CDC port found; pass --port")


class _Stream:
    """Buffered serial reader: big read(4096) + sliding-window sync (never
    byte-at-a-time). DBG1 diagnostics pass through untouched."""

    def __init__(self, ser):
        self.ser = ser
        self.buf = b""

    def fill(self):
        chunk = self.ser.read(4096)
        if not chunk:
            return False
        self.buf += chunk
        return True

    def drop(self, n):
        self.buf = self.buf[n:]


def _wait_ack(stream, param, timeout_s=5.0):
    """Wait for 'DBG1' 0xF9 <param>; True on match, False on 0xFF/timeout."""
    t0 = time.time()
    while time.time() - t0 < timeout_s:
        i = stream.buf.find(b"DBG1\xF9")
        if i >= 0 and i + 6 <= len(stream.buf):
            got = stream.buf[i + 5]
            stream.drop(i + 6)
            return got == param
        if not stream.fill():
            time.sleep(0.05)
    return False


def _capture_one(stream, w, h, timeout_s=10.0):
    """Capture one complete CAM2 frame; returns payload bytes or None."""
    t0 = time.time()
    while time.time() - t0 < timeout_s:
        hit = cam2_parse(stream.buf, w, h)
        if hit is not None:
            start, fw, fh = hit
            end = start + CAM2_HEADER + fw * fh
            frame = stream.buf[start + CAM2_HEADER:end]
            stream.drop(end)
            return frame
        if not stream.fill():
            time.sleep(0.05)
    return None


def main(argv=None):
    import argparse
    import json
    import os
    import time

    import serial  # CLI-only dependency

    p = argparse.ArgumentParser(
        description="OV7670 raw Bayer half-frame capture (CAM2 protocol)")
    p.add_argument("--port", default=None, help="CDC port (auto-detect if omitted)")
    p.add_argument("--out", default="bayer_frames", help="output directory")
    p.add_argument("--pairs", type=int, default=3, help="upper/lower frame pairs (default 3)")
    p.add_argument("--pattern", default=DEFAULT_PATTERN, help="CFA pattern (default RGGB)")
    p.add_argument("--bmp", action="store_true", help="also write demosaiced 640x480 BMP per pair")
    args = p.parse_args(argv)

    W, H = 640, 240  # pinned half-frame geometry (firmware RAW_BAYER)
    port = args.port or _find_port()
    os.makedirs(args.out, exist_ok=True)

    ser = serial.Serial(port, 115200, timeout=2)
    print(f"RAW_BAYER capture on {port} -> {args.out}/")
    ser.reset_input_buffer()
    stream = _Stream(ser)

    # First command MUST be 'T' upper: after init the window is full VGA.
    ser.write(b"T" + encode_bayer_window("upper"))
    if not _wait_ack(stream, 0x00):
        raise SystemExit("no 'T' upper ack from firmware")
    time.sleep(0.5)  # ~2 frames settle

    frames = []
    for i in range(args.pairs):
        ser.write(b"T" + encode_bayer_window("upper"))
        if not _wait_ack(stream, 0x00):
            raise SystemExit(f"pair {i}: no 'T' upper ack")
        time.sleep(0.5)
        upper = _capture_one(stream, W, H)
        if upper is None:
            raise SystemExit(f"pair {i}: upper frame sync timeout")
        ser.write(b"T" + encode_bayer_window("lower"))
        if not _wait_ack(stream, 0x01):
            raise SystemExit(f"pair {i}: no 'T' lower ack")
        time.sleep(0.5)
        lower = _capture_one(stream, W, H)
        if lower is None:
            raise SystemExit(f"pair {i}: lower frame sync timeout")

        up = np.frombuffer(upper, dtype=np.uint8).reshape(H, W)
        lo = np.frombuffer(lower, dtype=np.uint8).reshape(H, W)
        full = stitch_halves(up, lo)

        with open(os.path.join(args.out, f"upper_{i:03d}.raw"), 'wb') as f:
            f.write(upper)
        with open(os.path.join(args.out, f"lower_{i:03d}.raw"), 'wb') as f:
            f.write(lower)
        with open(os.path.join(args.out, f"frame_{i:03d}_640x480.raw"), 'wb') as f:
            f.write(full.tobytes())

        rec = {
            "index": i,
            "upper_mean": cfa_means(up, args.pattern),
            "lower_mean": cfa_means(lo, args.pattern),
            "stitched_mean": cfa_means(full, args.pattern),
        }
        frames.append(rec)

        if args.bmp:
            import bayer_demosaic
            rgb = bayer_demosaic.demosaic_bayer(full, pattern=args.pattern)
            with open(os.path.join(args.out, f"frame_{i:03d}_640x480.bmp"), 'wb') as f:
                f.write(bayer_demosaic.rgb_to_bmp(W, H, rgb))

        print(f"  pair {i}: upper={rec['upper_mean']} lower={rec['lower_mean']}")

    overall = {}
    for key in ("upper_mean", "lower_mean", "stitched_mean"):
        overall[key] = {ch: sum(f[key][ch] for f in frames) / len(frames)
                        for ch in "RGB"}
    stats = {"pattern": args.pattern, "pairs": args.pairs,
             "frames": frames, "overall": overall}
    with open(os.path.join(args.out, "stats.json"), "w") as f:
        json.dump(stats, f, indent=2)

    ser.close()
    print(f"wrote {args.pairs} pair(s) + stats.json to {args.out}/")


if __name__ == "__main__":
    main()

class SyncError(TimeoutError):
    pass


class SerialStream:
    """大块读 + 内部缓冲 (同 test_hw_integration.py 的硬约束)。"""

    CHUNK = 4096

    def __init__(self, s):
        self.s = s
        self.buf = b""

    def _fill(self, timeout):
        t0 = time.time()
        while time.time() - t0 < timeout:
            chunk = self.s.read(self.CHUNK)
            if chunk:
                self.buf += chunk
                return True
        return False

    def read_exact(self, n, timeout=5):
        t0 = time.time()
        while len(self.buf) < n and time.time() - t0 < timeout:
            self._fill(max(0.05, timeout - (time.time() - t0)))
        if len(self.buf) < n:
            raise SyncError(f"read_exact({n}) 超时, 仅收到 {len(self.buf)} B")
        out, self.buf = self.buf[:n], self.buf[n:]
        return out

    def sync(self, magic, timeout=5):
        t0 = time.time()
        keep = len(magic) - 1
        while time.time() - t0 < timeout:
            idx = self.buf.find(magic)
            if idx >= 0:
                self.buf = self.buf[idx + len(magic):]
                return
            self.buf = self.buf[-keep:]  # 防魔数跨块截断
            self._fill(max(0.05, timeout - (time.time() - t0)))
        raise SyncError(f"同步 {magic} 超时 ({timeout}s)")

    def drain(self):
        self.buf = b""
        self.s.reset_input_buffer()

    def _sync(self, magic, timeout=5):
        try:
            self.st.sync(magic, timeout)
        except SyncError as e:
            self.fail(str(e))

    def _read_exact(self, n, timeout=5):
        try:
            return self.st.read_exact(n, timeout)
        except SyncError as e:
            self.fail(str(e))

    def _read_dbg_packet(self, marker, timeout=5):
        self._sync(DBG1, timeout)
        m = self._read_exact(1, timeout=2)
        if m[0] != marker:
            self.fail(f"DBG1 后 marker 应为 0x{marker:02x}, 得到 0x{m[0]:02x}")
        return m

        time.sleep(0.5)  # ~2 帧窗口稳定

        self._sync(CAM2, timeout=8)

        self.assertEqual(len(raw), EXPECT_PAYLOAD, "载荷必须完整 153600 B")
        return np.frombuffer(raw, dtype=np.uint8).reshape(h, w)

        self._switch_window("upper")

                               f"{label} 半帧 CFA 三通道均值差应 >4 (分离), "

        pair = getattr(self.__class__, "pair", None)

            self._switch_window("lower")
            lower = self._capture_cam2()

        with tempfile.TemporaryDirectory() as d:

            with open(path, "wb") as f:
                f.write(bmp)
            with open(path, "rb") as f:
                self.assertEqual(f.read(), bmp, "落盘 BMP 与内存字节一致")

**证据** (官方组合 + 每-PCLK 采样):
- `'R'` 回读: 24/24 寄存器与官方组合期望匹配 (CLKRC=0x01, COM14=0x00, XSC=0x3A,
  YSC=0x35, DCWCTR=0x11, PCLK_DIV=0xF0, COM15=0xD0, COM7=0x01, 窗口全窗) — 组合确实落地。
- `'W'` 快速波形: HREF 高段中位 244µs。官方组合 PCLK_DIV=0xF0 → PCLK=fINT/2=5.2MHz,
  1280 PCLK × 192ns ≈ 246µs — 与 2 PCLK/byte (1280 PCLK/行) 吻合; 若 1 PCLK/byte
  (640 PCLK/行) 应为 61.5µs, 差 4 倍, 排除。
- `'T'` 上/下半帧 CAM2: **dup_even = 1.0000 (上/下半帧一致)** — 每-PCLK 采样下
  偶数/奇数列逐位全等, 即每 2 个 PCLK 才出现一个不同字节。取值 128 种、非零率 ~99%
  (真实图像特征, 排除全零/伪数据)。
