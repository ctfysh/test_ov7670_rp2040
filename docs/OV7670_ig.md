## General Description

The OV7670/OV7171 CAMERACHIP™ is a low voltage CMOS image sensor that provides the full functionality of a single-chip VGA camera and image processor in a small footprint package. The OV7670/OV7171 provides full-frame, sub-sampled or windowed 8-bit images in a wide range of formats, controlled through the Serial Camera Control Bus (SCCB) interface.

This product has an image array capable of operating at up to 30 frames per second (fps) in VGA with complete user control over image quality, formatting and output data transfer. All required image processing functions, including exposure control, gamma, white balance, color saturation, hue control and more, are also programmable through the SCCB interface. In addition, OmniVision CAMERACHIPS use proprietary sensor technology to improve image quality by reducing or eliminating common lighting/electrical sources of image contamination, such as fixed pattern noise (FPN), smearing, blooming, etc., to produce a clean, fully stable color image.

> **Note:** The OV7670/OV7171 uses a Pb lead-free package.

- High sensitivity for low-light operation

## Functional Description

The OV7670/OV7171 image sensor includes the following functional blocks:

- **Image Sensor Array** — total array of 656 × 488 pixels, with 640 × 480 active pixels (307,200)
- **Analog Signal Processor**
- **A/D Converters**
- **Test Pattern Generator**
- **Digital Signal Processor (DSP)**
- **Image Scaler**
- **Timing Generator**
- **Digital Video Port**
- **SCCB Interface**
- **LED and Strobe Flash Control Output**

### Functional Block Diagram (Text Representation)

```
XCLK → Clock → Timing Generator ──→ VSYNC, HREF, PCLK
                    │
SCCB Interface (SIO_C, SIO_D) ──→ Registers
                    │
Image Array (656×488) → Column Sense Amp → Analog Processing (AGC, AWB)
                                            │
                                        A/D Converter (10-bit)
                                            │
                            ┌───────────────┼───────────────┐
                            ▼               ▼               ▼
                        Test Pattern    DSP (Bayer→RGB,   Image Scaler
                        Generator       Edge Enhance,      → Digital Video Port
                                         Gamma, Lens       → D[7:0]
                                         Shading, etc.)
                            │
                        STROBE Output
```

### Image Sensor Array

The sensor has an image array of 656 × 488 pixels for a total of 320,128 pixels, of which 640 × 480 (307,200) are active. Each pixel is covered by a Bayer color filter array (CFA), with green pixels outnumbering red and blue 2:1 to match human visual sensitivity.

### Timing Generator

Controls:
- Array control and frame generation
- Internal timing signal generation and distribution
- Frame rate timing
- Automatic Exposure Control (AEC)
- External timing outputs (VSYNC, HREF/HSYNC, PCLK)

### Analog Signal Processor

Performs all analog image functions including Automatic Gain Control (AGC) and Automatic White Balance (AWB).

### A/D Converters

After the Analog Processing block, the Bayer pattern Raw signal is fed to a **10-bit A/D converter** shared by G and BR channels. Operating speed up to 12 MHz, fully synchronous to the pixel rate. Additional functions:
- Digital Black-Level Calibration (BLC)
- Optional U/V channel delay
- Additional A/D range controls

### Test Pattern Generator

- 8-bar color bar pattern
- Fade-to-gray color bar pattern
- Shift "1" in output pin

### Digital Signal Processor (DSP)

- Edge enhancement (2D high-pass filter)
- Color space converter (Raw → RGB or YUV/YCbCr)
- RGB matrix to eliminate color cross-talk
- Hue and saturation control
- White/black pixel correction
- De-noise
- Lens shading correction
- Programmable gamma control
- Transfer 10-bit data to 8-bit

### Image Scaler

Scales YUV/RGB output from VGA down to CIF and almost any size below CIF.

### SCCB Interface

The Serial Camera Control Bus (SCCB) controls all CAMERACHIP operations. Slave address: **0x42 for write, 0x43 for read**. Compatible with I²C signaling.

### LED and Strobe Flash Control

The OV7670 has a Strobe mode that allows it to work with an external flash and LED.

## Timing Specifications

### Key Timing Relationship

- **For Raw data:** `tP = tPCLK` (1 PCLK = 1 pixel)
- **For YUV/RGB:** `tP = 2 × tPCLK` (2 PCLKs = 1 pixel)

### Horizontal Timing

Each horizontal line consists of:
- **HREF active period:** 640 pixels × tP (data valid)
- **Horizontal blanking:** 144 tP (front porch + back porch)
- **Total line time:** 784 tP

### VGA Frame Timing

| Signal | Duration |
|---|---|
| VSYNC active (high) | 510 line-times |
| HREF active (high) | 480 line-times |
| Top invalid data | 10 line-times |
| Bottom invalid data | 17 line-times |
| Total frame | 510 lines |

### QVGA Frame Timing

QVGA HREF is derived from VGA HREF by selecting 1 out of every 4 rows (120 rows from 480).

### QQVGA Frame Timing

QQVGA HREF selects 1 out of every 4 rows (120 rows from 480), matching QVGA scaling.

### CIF Frame Timing

CIF HREF is 3/5 of VGA (288 rows from 480 horizontal, 352 columns from 640).

### QCIF Frame Timing

QCIF HREF is 3/5 of QVGA frame.

### RGB565 Output Timing

Each RGB565 pixel occupies **2 PCLK cycles** (high byte first, then low byte):

**High byte (first PCLK):**
| D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
|---|---|---|---|---|---|---|---|
| R4 | R3 | R2 | R1 | R0 | G5 | G4 | G3 |

**Low byte (second PCLK):**
| D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
|---|---|---|---|---|---|---|---|
| G2 | G1 | G0 | B4 | B3 | B2 | B1 | B0 |

### RGB555 Output Timing

**High byte (first PCLK):**
| D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
|---|---|---|---|---|---|---|---|
| X | R4 | R3 | R2 | R1 | R0 | G4 | G3 |

**Low byte (second PCLK):**
| D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
|---|---|---|---|---|---|---|---|
| G2 | G1 | G0 | B4 | B3 | B2 | B1 | B0 |

> **Note:** X = unused bit (always 0).
